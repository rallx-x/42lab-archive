# 명함 메이커 (기획 · 2026-11-07)

> 게임 안 「명함」 화면을 **진짜와 구분 안 될 만큼** 그대로 그려 주는 도구.
> 게임에서 얻지 못한 배경 · 테두리 · 칭호도 골라서 꾸밀 수 있게 → 고정 트윗용 안내 이미지로 쓰기.
> 지인끼리만 쓰는 도구 (사이트 메뉴에는 안 넣음).

---

## 1. 목표

- 결과물: **PNG 한 장** (게임 화면과 같은 1920×1080, 또는 명함 판만 잘라서)
- 「진짜 같음」이 제일 중요 → 위치 · 크기 · 글꼴 · 색 · 그림은 게임 그대로, 바꿀 수 있는 건 **내용만**
- **뺄 것**: 이름 옆 연필(편집) 아이콘
- 소개글 칸 = 안내사항 적는 곳 (게임은 짧은 한 줄이지만 여기선 여러 줄 허용, 칸 크기는 그대로)

## 2. 어디에 둘지 (정할 것)

| 방법 | 장점 | 단점 |
|---|---|---|
| 사이트 숨은 주소 (예: `#namecard`, 메뉴 · 검색에 안 나옴) | 그림 · 인형 데이터 그대로 씀, 고치면 바로 반영 | 주소 아는 사람은 다 들어옴 |
| HTML 파일 하나로 따로 | 완전히 지인 전용 | 그림은 pnc-item 에서 불러와야 함, 고칠 때마다 다시 보내야 함 |

→ 추천: **숨은 주소**

## 5. 필요한 그림 · 글꼴 (사용자 클라이언트에서 뽑기)

**그림 (→ pnc-item `namecard/` 폴더)**
- [ ] 명함 배경 `UserInfo_*` (109) — 큰 그림, 화질 제일 중요
- [ ] 프로필 테두리 `UsertHeadFrame_*` (109) — 움직이는 테두리 `dyn_frame` 은 첫 장만
- [ ] 칭호 띠 `ICON_Item_620xxx` (33) — 띠 모양 그대로인지 확인 (아이템 아이콘일 수도 → 띠 원본 따로 찾기)
- [ ] 명함 UI 조각: 흰 판 · 회색 소개글 칸 · 검은 제목 띠 · LV/UID 상자 · 조력 인형 칸 · 작전 능력 막대(번개) · 레이더 바탕 · 등급 글자 상자 · 의식 동기화 띠 · 업적 달성도 알약 · 단추들 · 42LAB 로고 · QR
  → 사용자 정보 화면 프리팹 / 아틀라스 (이름에 `UserInfo` · `PlayerInfo` · `Personal` 들어간 묶음 찾기)
- [ ] 인형 조력 칸 얼굴 (게임은 네모 얼굴 + 직군 아이콘 + 레벨 + 별) — 지금 사이트 얼굴과 같은 그림인지 확인

**글꼴 (진짜 같음의 핵심)**
- [ ] 숫자 · 영문 좁은 글꼴 (「LV.30」「UID:106209」「11913」「2022-11-23」「OASIS CLOUD …」) — 클라이언트 폰트 파일 (ttf/otf 또는 TMP 폰트 에셋)
- [ ] 한글 본문 글꼴 (이름 · 소개글 · 「조력 인형」)
- [ ] 칭호 띠의 기울어진 굵은 글꼴

## 6. 만드는 방식

- `<canvas>` 1920×1080 에 차례로 그리기 → `toBlob` 으로 PNG 저장
- 화면 미리보기는 줄여서 보여 주고, 저장은 원래 크기
- 배경 그림은 오른쪽에 붙이고 왼쪽으로 흰색 번짐(그라데이션) — 게임과 같은 폭 · 세기로
- 레이더: 등급 → 길이 (S > A > B > C > D > E), 진한 파랑 / 연한 파랑 두 겹 (게임 모양 다시 확인)
- 저장한 설정은 브라우저에 기억 (다음에 열면 그대로)

## 7. 맞추기 방법 (진짜 같게)

1. 사용자 스크린샷 1920×1080 을 밑에 깔고, 만든 그림을 반투명으로 겹쳐 보기 (확인 모드)
2. 같은 내용(먀로 명함)을 넣어서 **차이 나는 곳이 없을 때까지** 위치 · 글자 크기 · 자간 조정
3. 다른 해상도 캡처(첫 스크린샷 「White」 2000×923, 휴대폰 비율)도 비교 → 휴대폰 비율 판도 만들지 결정

## 8. 확인할 것

- [ ] `title.position` 1 · 2 가 앞말 · 뒷말이 맞는지 (「스에요이의」 + 「운명의 사람」)
- [ ] 칭호 띠 그림이 아이템 아이콘과 같은지
- [ ] 프로필 그림 목록 (게임에서 고를 수 있는 프로필이 인형 얼굴 말고도 있는지 — 「White」 명함은 콜라보 SD 얼굴)
- [ ] 레이더 등급별 길이
- [ ] 아래 버전 글자 「OASIS CLOUD OPERATING SYSTEM VER 2.0.0.18」 — 게임 버전 따라 바뀜 (입력 칸으로)
- [ ] 휴대폰 비율 판 필요 여부

## 9. 순서

1. 그림 · 글꼴 뽑기 (사용자) → pnc-item 올리기
2. `tools/client_extract/namecard.py` → `data/<언어>/namecard.json` (배경 · 테두리 · 칭호 · 칭호 띠 목록)
3. 숨은 화면 `#namecard` — 입력 칸 + 캔버스 미리보기 + PNG 저장
4. 스크린샷 겹쳐서 맞추기
5. 지인 테스트
